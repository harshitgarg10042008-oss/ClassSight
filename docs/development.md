# Development

Use `python scripts/dev.py up`, `down`, `status`, `reset`, `seed`, or `test` for the local lifecycle. Copy `.env.example` to `.env` before starting. The development teacher is `teacher / teacher123`; do not use that account outside local development.

The active recognition work is kept on `demo-fixes` until the full API and browser merge gate is green. Do not change the detector or recognition thresholds without updating the calibration evidence.
